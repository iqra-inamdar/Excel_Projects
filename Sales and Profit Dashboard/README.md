# 📊 Sales & Profit Dashboard 

## 📌 Project Overview

This project focuses on analyzing sales performance, profitability, customer contributions, and monthly business trends using Microsoft Excel.

The dashboard transforms sales data into meaningful business insights through interactive visualizations, KPI cards, PivotTables, PivotCharts, and slicers.

## 🎯 Dashboard Features

- **Total Sales:** Displays overall sales performance.
- **Total Profit:** Tracks overall profitability.
- **Sales by Category:** Compares sales across product categories.
- **Profit by Year:** Analyzes yearly profit trends.
- **Customer Count:** Visualizes customer distribution by year.
- **Sales by State:** Shows geographical sales performance.
- **Top 5 Customers:** Highlights customers generating the highest profit.
- **Sales by Month:** Identifies monthly sales trends.
- **Interactive Slicers:** Filters data by category, year, and month.

## 🛠️ Tools & Techniques Used

- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and Interactive Filters
- KPI Cards
- Data Visualization
- Sales Data Analysis

## 📚 Key Learnings

- Building interactive Excel dashboards.
- Cleaning and organizing data for analysis.
- Creating PivotTables and PivotCharts.
- Analyzing sales and profitability trends.
- Using slicers to explore data dynamically.
- Presenting business insights through effective visualizations.

## 📈 Project Outcome

This project demonstrates how Microsoft Excel can be used to convert sales data into an interactive dashboard for business reporting and decision-making.
