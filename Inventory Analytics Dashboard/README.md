# 📊Inventory Analytics Dashboard

## 📌 Project Overview

This project presents an interactive Inventory Analytics Dashboard developed using Microsoft Excel to monitor inventory performance, stock availability, sales, purchases, and warehouse operations.

The dashboard provides meaningful insights into inventory management through interactive slicers, KPI cards, and dynamic visualizations.

## 🎯 Dashboard Features

- **Total Inventory Value:** Tracks the overall value of available inventory.
- **Total Stock Quantity:** Displays the total quantity of stock.
- **Low Stock Items:** Identifies products requiring restocking.
- **Total Sales Value:** Monitors overall sales performance.
- **Total Purchase Value:** Tracks purchasing expenses.
- **Average Unit Price:** Displays the average product unit price.
- **Monthly Sales vs Purchase Trend:** Compares monthly sales and purchases.
- **Inventory Value by Category:** Analyzes inventory value across categories.
- **Top 10 Products Above Reorder Level:** Highlights products based on reorder levels.
- **Inventory Turnover by Category:** Evaluates inventory movement.
- **Stock Status Breakdown:** Analyzes in-stock, low-stock, and out-of-stock items.
- **Purchase Value by Supplier:** Compares supplier-wise purchase values.
- **Stock Quantity by Warehouse:** Analyzes warehouse-wise stock distribution.
